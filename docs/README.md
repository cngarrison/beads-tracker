# Beads Tracker user guide

How to use Beads Tracker, the macOS app for the [beads](https://github.com/gastownhall/beads/)
(`bd`) issue tracker. For how the app works inside, see [CONTRIBUTING.md](../CONTRIBUTING.md)
and the developer notes in [dev-docs/](../dev-docs/).

1. [Getting started](getting-started.md): install, open a repository, windows and live updates
2. [Browsing and filtering](browsing.md): the issue list, search, the detail panel
3. [Creating and editing issues](creating-and-editing.md): the create form, drafts, editing,
   status, comments, dependencies and dates
4. [Reviewing issues](reviewing.md): Find in details, Needs you, the Claude brief, replies in
   Notes, and the review settings
5. [Troubleshooting](troubleshooting.md): `bd` not found, live updates, the log file

## Keyboard shortcuts

| Shortcut | Action |
|---|---|
| `⌘N` | New window |
| `⌘R` | Re-read all issues |
| `⌘F` | Search the list |
| `⌥⌘F` | Find in the details of the issues shown |
| `⌘↵` | Fill in the form from your description (Describe), create the issue (create form), save (edit sheet), or record a reply |
| `Esc` | Cancel the create form, edit sheet or reply |
